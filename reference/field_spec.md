# 招生计划与投档数据统一字段

项目按源表实际含义写入字段；源文件没有的字段留空，不推测、不补造。

## 公共追溯字段

`年份`、`省份`、`数据类型`、`招生类型`、`批次`、`科类`、`计划类别`、`来源文件`、`来源页`、`来源工作表`、`来源行`、`提取方式`、`原始行文本`、`版式`。

## 招生计划字段

`院校代码`、`院校全称`、`院校名称`、`院校所在地区`、`院校性质`、`院校计划总数`、`院校专业组代码`、`专业组代码`、`科目要求`、`院校专业组名称`、`专业组计划数`、`专业代码`、`专业名称及专业方向`、`专业名称及招考方向`、`再选科目`、`分数线`、`计划数`、`学制`、`收费标准`、`学费`、`外语语种`、`是否口试`、`备注`。

## 投档数据字段

`院校代码`、`院校名称`、`院校专业组代码`、`专业组代码`、`专业组名称`、`专业代码`、`专业名称及专业方向`、`计划数`、`投档人数`、`最高分`、`最低分`、`最低分名次`、`语文`、`数学`、`外语`、`综合`、`语数成绩`、`语数最高成绩`、`首选科目`、`再选科目最高成绩`、`志愿号`。

## 强制规则

- 所有代码按文本保存并保留前导零。
- 人数、计划、学制、学费、分数、名次只接受来源中明确存在的数字。
- `/`、`—`、空白、无生源和投档人数为 0 的记录保留原值或空值，并进入 `review`。
- 不同表没有的字段允许为空；不得为了统一列而猜测。
- 同一批源文件最终只生成一个工作簿，字段取所有已识别结构的并集。
- `来源文件`、页码/工作表和原始行必须保留，便于回查。
