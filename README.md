# 高考招生数据 ETL 流水线

这是一个用于整理中国各省高考招生计划、征集志愿计划和投档数据的本地流水线。

它可以接收 PDF、扫描图片以及原始 Excel，并将同一任务目录中的全部源文件汇总为一份结构化 Excel。无法可靠确认的记录会进入 `review`，未知版式会安全停止，不会强行输出疑似正确的数据。

## 主要能力

- 原始 Excel 直接读取，不使用 OCR。
- 文本型 PDF 优先直接提取文字和表格。
- 扫描 PDF、JPG、PNG 等图片使用本地 RapidOCR。
- 支持院校、专业组、专业的层级识别和父级字段向下填充。
- 支持计划数、学制、学费、选科、备注、投档分数和位次等常见字段。
- 同一省份、年份或任务目录最终只生成一份汇总工作簿。
- 提供互斥的 `data`/`review`、聚合复核案例 `review_cases`、`audit`、`metadata` 以及必要汇总表。
- 对可观察版式执行源数据单元与输出记录的完整性计数；损坏关键代码的行优先保留到`review`，禁止静默丢弃。
- 关键字段保留原始值、局部复识值、最终值和判定状态；未决风险没有进入`review`时禁止导出。
- 页面提取与网格单元格OCR均支持持久缓存，运行报告提供分阶段耗时和缓存统计。

## 环境

- Windows
- Python 3.12
- 项目根目录中的独立 `.venv`
- RapidOCR + ONNX Runtime

## 日常使用

将源文件放入：

```text
input/raw/省份/年份/
```

从项目根目录启动 Claude Code，然后执行：

```text
/pdf-to-excel 省份/年份
```

例如：

```text
/pdf-to-excel hebei/2026
```

生成的汇总文件位于：

```text
output/excel/省份/年份/
```

详细规则参见 `用户操作说明书.md` 和 `RUNBOOK.md`。

## 数据安全

Git 只管理代码、测试、配置、项目 Skill 和文档。以下内容默认不会提交：

- 原始 PDF、图片和 Excel；
- 生成的 Excel；
- OCR 缓存、临时文件和运行日志；
- Python 虚拟环境；
- `.env` 和 Claude Code 本机权限配置。

提交前仍应检查暂存文件，确保没有包含账号、密码、Token、Cookie、私钥或真实招生数据。

## 准确性说明

`data` 表示通过自动规则校验的记录，不等于人工确认 100% 正确。首次遇到一种新版式时必须做源表逐行或金标准回归，不能仅凭输出行数和少量抽样宣称无遗漏；`review_cases`用于降低重复复核，`review`保留全部待核记录。
